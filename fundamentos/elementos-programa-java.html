Fundamentos de Java

Elementos de un Programa Java

Domina los componentes básicos que construyen cualquier programa Java: comentarios, variables, tipos de datos, operadores y expresiones. Aprenderás no solo la sintaxis, sino también por qué cada elemento existe y cómo usarlo correctamente.

🔬 Elemento Signature: Desglosa una línea de código

Haz clic en cada parte para ver qué elemento Java es:

final double PI = 3.1415926536 ;
→ Haz clic en cualquier parte arriba para ver su explicación

Comentarios

Los comentarios son texto que escribes para explicar tu código, pero que Java ignora completamente al compilar. Son para los humanos, no para la máquina.

💡 Piénsalo así: Un comentario es como escribir notas al margen de un libro. El autor (Java) no lee tus notas; solo leen los que estudian el libro (otros programadores, o tú en el futuro).

Tres tipos de comentarios

Línea simple (//)

Comienza con // y termina al final de la línea. Úsalo para explicar un detalle rápido.

Bloque (/* */)

Comienza con /* y termina con */. Puede abarcar varias líneas. Ideal para explicar secciones completas.

Documentación (/** */)

Comienza con /** y termina con */. Especial: la herramienta javadoc genera documentación automática a partir de estos.

Ejemplos de cada tipo

// Comentario de una línea: declare la constante PI
final double PI = 3.1415926536;

/*
 * Comentario de bloque: este programa calcula
 * el perímetro de una circunferencia.
 * Entrada: radio (double)
 * Salida: perímetro (double)
 */

/**
 * Calcula el perímetro de una circunferencia
 * @param radio el radio de la circunferencia
 * @return el perímetro calculado
 * @author Luis Mendoza
 * @version 1.0
 */
✓ Buen uso: Comenta el "por qué" no el "qué". "Por qué": explica la decisión detrás del código. "Qué": es obvio si lees el código. 
// ❌ MALO: comentario obvio
PI = PI + 1; // Suma 1 a PI

// ✓ BUENO: explica la decisión
// Usamos double en lugar de float para mayor precisión
// en cálculos de astronomía
final double PI = 3.1415926536;

Identificadores

Un identificador es un nombre que tú eliges para variables, métodos, clases, constantes, etc. Java tiene reglas muy estrictas sobre qué nombres son válidos.

💡 Piénsalo así: Los identificadores son etiquetas que pegas en cajas. La caja puede contener cualquier cosa, pero la etiqueta debe seguir reglas (no puede tener caracteres raros, no puede comenzar con número, etc.).

Reglas obligatorias

  • ✓ Debe comenzar con una letra (a-z, A-Z), guion bajo (_) o símbolo de dólar ($)
  • ✓ Puede contener letras, dígitos (0-9), guiones bajos (_) o dólares ($)
  • ✓ Sensible a mayúsculas: nombre, Nombre y NOMBRE son tres identificadores distintos
  • ❌ No puede ser una palabra reservada de Java (veremos la lista después)
  • ❌ No puede contener espacios, guiones normales (-), ni otros símbolos

Ejemplos válidos e inválidos

Identificador ¿Válido? Razón
radio ✓ SÍ Comienza con letra, contiene solo letras
radio2 ✓ SÍ Letras y dígitos permitidos
_radio ✓ SÍ Guion bajo al inicio es válido
2radio ❌ NO Comienza con dígito
radio-2 ❌ NO Contiene guion normal (-), no permitido
radio 2 ❌ NO Contiene espacio
int ❌ NO Palabra reservada de Java

Convenciones de nombres en Java

No son obligatorias, pero todos los programadores Java las siguen. Aumentan la legibilidad:

📦 Clases

Comienzan con mayúscula. Palabras compuestas en PascalCase sin guiones bajos.
Ejemplos: HolaMundo, Circulo, GestorBancario

📝 Variables y métodos

Comienzan con minúscula. Palabras compuestas en camelCase sin guiones bajos.
Ejemplos: radio, calcularPerimetro, edadEstudiante

🔒 Constantes

Todas en MAYÚSCULAS. Palabras separadas por guiones bajos (_).
Ejemplos: PI, VELOCIDAD_LUZ, TOTAL_ESTUDIANTES

Ejemplos en contexto

// ✓ CORRECTO: sigue convenciones Java
public class CalculadoraGeometrica {  // Clase: PascalCase
    final double PI = 3.1415926536;  // Constante: MAYÚSCULAS

    public double calcularPerimetro(double radio) {  // Método: camelCase
        double perimetro = 2 * PI * radio;  // Variable: camelCase
        return perimetro;
    }
}

Variables y Valores

Una variable es un contenedor con un nombre que almacena un valor. Puedes cambiar el valor dentro, pero el tipo debe mantenerse igual.

💡 Piénsalo así: Una variable es como una caja etiquetada en tu escritorio. Pones algo en la caja (valor), le das un nombre (identificador), y especificas qué tipo de cosa va en esa caja (tipo de dato). Si la caja dice "solo números enteros", no puedes meter un texto dentro.

Partes de una variable

int edad = 25;
↑    ↑     ↑  ↑
|    |     |  └─ Valor inicial (literal)
|    |     └──── Operador de asignación
|    └────────── Identificador (nombre)
└─────────────── Tipo de dato

Declaración e inicialización

Declaración

Indicarle a Java que existe una variable y qué tipo tiene:
int edad;

Inicialización

Asignarle un valor inicial:
edad = 25;

Ambas a la vez

Declarar e inicializar en una sola línea:
int edad = 25;

Ejemplos: múltiples formas

// Forma 1: Declarar sin inicializar
int numero;

// Forma 2: Inicializar después
numero = 42;

// Forma 3: Declarar e inicializar en una línea
int numero2 = 42;

// Forma 4: Múltiples variables del mismo tipo
int x = 1, y = 2, z = 3;

// Forma 5: Constante (no cambia)
final double VELOCIDAD_LUZ = 299792458;  // m/s
// VELOCIDAD_LUZ = 1000;  // ❌ Error: no puedes cambiar una constante

Cambiar el valor de una variable

int edad = 25;
System.out.println(edad);  // Salida: 25

edad = 26;  // Cambiar el valor
System.out.println(edad);  // Salida: 26

edad = edad + 1;  // Usar el valor anterior en el cálculo
System.out.println(edad);  // Salida: 27

Tipos de Datos Primitivos

Java proporciona ocho tipos primitivos: tipos básicos que representan números, caracteres y valores lógicos. Son los "ladrillos" con que construyes tipos más complejos.

💡 Piénsalo así: Los tipos primitivos son como tallas de cajas en un almacén. Tienes cajas para números pequeños (byte), números grandes (long), decimales (double), caracteres (char) y valores sí/no (boolean). Cada tipo ocupa un tamaño específico de memoria.

Tabla de tipos primitivos

Tipo Bytes Rango Descripción
byte 1 -128 a 127 Entero muy pequeño (raramente usado)
short 2 -32,768 a 32,767 Entero pequeño (poco usado)
int 4 -2,147,483,648 a 2,147,483,647 Entero estándar (lo más común para enteros)
long 8 -9,223,372,036,854,775,808 a +9,223,372,036,854,775,807 Entero muy grande (IDs, marcas de tiempo)
float 4 ±3.4 × 10³⁸ (aprox. 6-7 dígitos decimales) Decimal de baja precisión (raro)
double 8 ±1.7 × 10³⁰⁸ (aprox. 15-17 dígitos decimales) Decimal de alta precisión (estándar para decimales)
char 2 '\u0000' a '\uffff' (0 a 65,535) Un solo carácter Unicode
boolean 1 true o false Valor lógico verdadero/falso

Cuándo usar cada tipo: recomendaciones prácticas

int (enteros)

Edad, cantidad de estudiantes, índices de arrays. Es el "default" para números enteros. Usa int a menos que tengas una razón específica para otra cosa.

double (decimales)

Calificaciones, precios, distancias, cualquier número con decimales. Usa double siempre para decimales.

long (enteros muy grandes)

IDs de base de datos, marcas de tiempo (millisegundos desde 1970), números de teléfono largos.

boolean (lógicos)

Banderas de control, condiciones: boolean estáRegistrado = true;

char (caracteres)

Un solo carácter: char inicial = 'L';. Para texto de varias letras usa String (no es primitivo).

byte, short, float (raros)

Necesitan casos especiales: byte para arrays de datos binarios, short/float casi nunca. Evítalos en código principiante.

Ejemplos de declaración

// Enteros
byte calificacion = 95;        // 0 a 100
short año = 2024;          // años recientes
int poblacion = 1000000;   // población de ciudad
long idUsuario = 9876543210L;  // Nota: sufijo L

// Decimales
float aproximado = 3.14f;       // Nota: sufijo f
double preciso = 3.1415926536;

// Caracteres y lógicos
char inicial = 'L';
boolean esActivo = true;
boolean esPrueba = false;
⚠️ Atención a los sufijos: long requiere L al final (100L), y float requiere f (3.14f). Si no los pones, Java asume que es int o double.

Literales

Un literal es un valor escrito tal cual en el código. Es la forma en que escribes valores concretos para que Java los entienda.

💡 Piénsalo así: Si una variable es una caja, el literal es la cosa que metes en la caja. 42 es un literal entero, "Hola" es un literal de texto, 3.14 es un literal decimal.

Literales enteros

// Decimal (lo más común)
int numero = 42;
int negativo = -100;

// Octal (prefijo 0, poco usado)
int octal = 010;  // Representa 8 en decimal

// Hexadecimal (prefijo 0x, usado en colores, direcciones)
int hexadecimal = 0x2A;  // Representa 42 en decimal
int color = 0xFF5733;     // Código RGB

// Números muy grandes: usa long con sufijo L
long granNumero = 10000000000L;

Literales decimales

// double (estándar)
double pi = 3.1415926536;
double negativo = -2.5;

// Notación científica (útil para números muy grandes o pequeños)
double velocidadLuz = 2.99792458e8;  // 299,792,458
double pequeño = 1.5e-10;        // 0.00000000015

// float (con sufijo f)
float aproximado = 3.14f;

Literales de carácter

// Caracteres normales (entre comillas simples)
char letra = 'A';
char digito = '5';
char espacio = ' ';

// Caracteres especiales (secuencias de escape)
char tabulacion = '\t';  // Tab
char saltoLinea = '\n';  // Salto de línea
char comilla = '\'';     // Comilla simple (escapeada)

// Caracteres Unicode (por código)
char letra_espanola = '\u00F1';  // ñ

Literales de texto (String)

// Nota: String NO es un tipo primitivo, pero lo usamos todo el tiempo
String nombre = "Luis";
String mensaje = "Hola, ¿cómo estás?";
String vacio = "";  // Cadena vacía

// Secuencias de escape en texto
String conTabs = "Nombre\tEdad\tCiudad";
String multilinea = "Línea 1\nLínea 2\nLínea 3";

Literales booleanos

boolean verdadero = true;
boolean falso = false;

// Los literales booleanos son siempre true o false (minúsculas)
// Nota: ❌ True, False, TRUE no son válidos
Error común 1: Confundir comillas. Caracteres usan comillas simples 'A', textos usan comillas dobles "Hola". 'Hola' es un error.
Error común 2: Olvidar sufijos. long requiere L, float requiere f. int x = 10000000000; overflow, usa long x = 10000000000L;
Error común 3: Números con separadores. Java permite 1_000_000 (equivale a 1000000) para legibilidad, pero 1.000.000 (con puntos) está mal.

Operadores

Un operador es un símbolo que realiza una acción sobre uno o más valores (operandos). Java tiene operadores para aritmética, comparación, lógica, asignación y más.

Operadores aritméticos

Operador Nombre Ejemplo Resultado
+ Suma 5 + 3 8
- Resta 5 - 3 2
* Multiplicación 5 * 3 15
/ División 15 / 3 5
% Módulo (resto) 17 % 5 2
++ Incremento x++ o ++x Suma 1 a x
-- Decremento x-- o --x Resta 1 a x

Operadores de asignación

Operador Descripción Ejemplo Equivale a
= Asigna valor x = 5 -
+= Suma y asigna x += 3 x = x + 3
-= Resta y asigna x -= 3 x = x - 3
*= Multiplica y asigna x *= 2 x = x * 2
/= Divide y asigna x /= 2 x = x / 2

Operadores de comparación

Operador Descripción Ejemplo Resultado (si x=5)
== Igual a x == 5 true
!= No igual a x != 3 true
< Menor que x < 10 true
> Mayor que x > 3 true
<= Menor o igual x <= 5 true
>= Mayor o igual x >= 5 true

Operadores lógicos

// AND lógico (&&): ambos deben ser true
if (edad >= 18 && tieneLicencia) {
    System.out.println("Puedes conducir");
}

// OR lógico (||): al menos uno debe ser true
if (esFinSemana || esVacacion) {
    System.out.println("¡A descansar!");
}

// NOT lógico (!): invierte true ↔ false
if (!estáLloviendo) {
    System.out.println("Vamos al parque");
}

Concatenación de textos

// El operador + también concatena strings
String nombre = "Luis";
int edad = 30;

String resultado = "Mi nombre es " + nombre + " y tengo " + edad + " años";
System.out.println(resultado);
// Salida: Mi nombre es Luis y tengo 30 años

Precedencia de operadores

Cuando tienes varios operadores, Java los ejecuta en cierto orden (de mayor a menor precedencia):

Orden (de más alto a más bajo): Paréntesis () → Multiplicación/División/Módulo (*, /, %) → Suma/Resta (+, -) → Comparación (<, >, ==, !=) → AND lógico (&&) → OR lógico (||) 
// Ejemplos de precedencia
int resultado = 2 + 3 * 4;  // 14, no 20 (primero 3*4, luego +2)

int resultado2 = (2 + 3) * 4;  // 20 (paréntesis primero)

boolean test = 5 > 3 && 2 < 10;  // true (ambas condiciones se evalúan)

Expresiones

Una expresión es una combinación de valores, variables y operadores que Java evalúa para producir un resultado.

💡 Piénsalo así: Si una sentencia es una frase completa, una expresión es una parte de esa frase. 2 + 3 es una expresión que da como resultado 5. Cuando lo asignas a una variable (x = 2 + 3), tienes una sentencia.

Tipos de expresiones

Aritmética

Produce un número: 2 + 3 * 4 (resultado: 14)

Comparación

Produce un booleano: edad > 18 (resultado: true o false)

Lógica

Produce un booleano: x > 0 && x < 100 (resultado: true o false)

Asignación

Asigna un valor y devuelve ese valor: x = 5 (resultado: 5)

Ejemplos en contexto

// Expresión aritmética
double perimetro = 2 * 3.14159 * 5;  // Expresión: 2 * 3.14159 * 5

// Expresión de comparación
boolean esAdelescente = edad >= 13 && edad <= 19;

// Expresión compleja
double promedio = (calificacion1 + calificacion2 + calificacion3) / 3;

// Asignación anidada
int x, y, z;
x = y = z = 10;  // Todos obtienen 10

// Incremento en expresión
int contador = 0;
System.out.println(++contador);  // Imprime 1 (incrementa primero)
System.out.println(contador++);  // Imprime 1 (imprime luego incrementa)
System.out.println(contador);    // Imprime 2
Error común 1: Diferencia entre ++x (pre-incremento) y x++ (post-incremento). En la mayoría de casos dan el mismo resultado, pero en expresiones pueden diferir.
Error común 2: Usar = en lugar de == en condiciones. if (x = 5) asigna 5 a x, no compara. Usa if (x == 5).

Expresiones Aritméticas y Lógicas

Ahora combinaremos operadores aritméticos y lógicos en expresiones más complejas, que son el corazón de cualquier programa.

Expresiones aritméticas: paso a paso

// Ejemplo 1: Cálculo del área de un rectángulo
double largo = 5.5;
double ancho = 3.2;
double area = largo * ancho;  // 17.6

// Ejemplo 2: Convertir temperatura de Celsius a Fahrenheit
double celsius = 25;
double fahrenheit = (celsius * 9 / 5) + 32;  // 77

// Ejemplo 3: Calcular descuento
double precioOriginal = 100;
double porcentajeDescuento = 15;
double precioFinal = precioOriginal - (precioOriginal * porcentajeDescuento / 100);  // 85

Expresiones lógicas: decisiones complejas

// Validar si un número está en rango
int numero = 42;
boolean enRango = numero >= 1 && numero <= 100;  // true

// Validar acceso: mayor de edad Y tiene documento
int edad = 20;
boolean tieneDocumento = true;
boolean puedeEntrar = edad >= 18 && tieneDocumento;  // true

// Validar si es fin de semana O es día festivo
String dia = "sábado";
boolean esFeriva = dia.equals("sábado") || dia.equals("domingo");  // true

// Invertir lógica: si NO está disponible
boolean disponible = false;
boolean noDisponible = !disponible;  // true

Combinación de aritmética y lógica

// Validar si una calificación es válida (0-100) y aprobó (>= 60)
double calificacion = 75.5;
boolean esValida = calificacion >= 0 && calificacion <= 100;
boolean aprobo = calificacion >= 60;

if (esValida && aprobo) {
    double porcentaje = (calificacion / 100) * 100;  // Redundante, pero lo hago para el ejemplo
    System.out.println("¡Aprobaste con " + calificacion + "!");
} else if (esValida && !aprobo) {
    System.out.println("No aprobaste, nota: " + calificacion);
} else {
    System.out.println("Calificación inválida");
}

Conversión de Tipos

A veces necesitas cambiar un valor de un tipo a otro (p. ej., de double a int). Java permite esto, pero tienes que saber cuándo es seguro y cuándo pierdes información.

💡 Piénsalo así: Convertir de un tipo a otro es como cambiar el formato de un archivo. Puedes convertir sin pérdida (double → int es posible pero pierdes decimales), o puedes convertir con riesgo si los valores se salen del rango del tipo destino.

Conversión implícita (automática)

Java la hace automáticamente cuando es seguro (de un tipo "menor" a uno "mayor"):

// byte → short → int → long → float → double

int numeroEntero = 42;
double numeroDecimal = numeroEntero;  // Conversión automática: 42.0

byte pequeño = 10;
int grande = pequeño;  // Conversión automática: 10

Conversión explícita (casting)

Tú le dices a Java exactamente qué tipo quieres, usando paréntesis:

// De double a int (PIERDES los decimales)
double precio = 19.99;
int precioRedondeado = (int) precio;  // 19 (se pierden los .99)

// De long a int (cuidado si el valor es muy grande)
long numeroGrande = 5000000000L;
int numeroChico = (int) numeroGrande;  // ⚠️ Overflow: resultado impredecible

// De String a int (requiere el método Integer.parseInt())
String texto = "42";
int numero = Integer.parseInt(texto);  // 42

Tabla de conversiones seguras

De A Seguro Nota
int double ✓ Automática. Resultado: 42.0
double int ❌ Requiere casting. Pierdes decimales. (int)3.99 = 3
int long ✓ Automática. Seguro.
long int ❌ Requiere casting. Riesgo de overflow si valor > 2.1 mil millones
double float ❌ Requiere casting: (float)3.14. Posible pérdida de precisión.
String int ❌ Usa Integer.parseInt("42"). Falla si el texto no es número.

Ejemplos prácticos

// Caso 1: Redondear un número decimal
double valor = 7.8;
int redondeado = (int)(valor + 0.5);  // 8 (agregamos 0.5 antes de convertir)

// Caso 2: Obtener el resto sin decimales
double resultado = 17 / 5;      // 3.4 (división de doubles)
int resultadoInt = 17 / 5;  // 3 (división de ints, sin decimales)

// Caso 3: Convertir entrada de usuario (texto) a número
String edadTexto = "25";
int edad = Integer.parseInt(edadTexto);  // 25 (como número)

// Caso 4: Convertir número a texto
int numero = 42;
String numeroTexto = String.valueOf(numero);  // "42"
Error común 1: Divisiones que pierden información. int x = 17 / 5; da 3, no 3.4. Si quieres decimales, haz double x = 17.0 / 5.0;
Error común 2: Overflow en casting. (int)9000000000L no da error pero el resultado es impredecible. Comprueba que el valor esté en rango antes de castear.
Error común 3: Convertir String a número sin validar. Integer.parseInt("abc"); lanza una excepción. Siempre valida que el texto sea un número válido.

💡 Piénsalo así: Las palabras reservadas son señales de tráfico: ALTO, CEDA, GIRE. Si intentas nombrar una variable "ALTO", Java te dice "no, eso ya significa algo especial". Necesitas elegir otro nombre.

Las palabras reservadas más comunes (por ahora)

A medida que avances en el curso, entenderás para qué sirve cada una. Por ahora, estas son las más importantes:

// Tipos primitivos
int, double, boolean, char, long, float

// Definición de clases y métodos
public class MiClase { ... }
public static void main(String[] args) { ... }

// Control de flujo (veremos después)
if (...) { ... } else { ... }
for (...) { ... }
while (...) { ... }

// Valores especiales

Error común 1: Usar una palabra reservada como nombre de variable. int if = 5; da error. Usa int condicion = 5;
Error común 2: Confundir null ("nada") con 0 (número cero) o "" (texto vacío). Son distintos.

Principio de Pareto: El 80/20

Aquí están las 5 reglas que explican el 80% de lo que necesitas saber sobre elementos de un programa Java:

  • Siempre declara variables con su tipo. int x = 5; Esto permite a Java verificar que usas los valores correctamente.
  • Comenta el "por qué", no el "qué". Tu código debe explicarse a sí mismo. Los comentarios explican decisiones no obvias.
  • Usa int y double como tus tipos por defecto. Casi siempre funcionan. Otros tipos (byte, long, float) son para casos especiales.
  • La precedencia de operadores importa. Cuando tengas duda, usa paréntesis: (a + b) * c es más claro que a + b * c.
  • Las conversiones de tipos pueden perder información. Cuando conviertes double a int, pierdes decimales. Hazlo conscientemente.

Haz clic en cada pregunta para revelar la respuesta. Intenta responder ANTES de hacer clic.

¿Cuál es la diferencia entre un comentario // y /* */?

// comenta hasta el final de la línea actual. /* */ puede abarcar varias líneas. Ambos son ignorados por Java al compilar.

¿Cuál de estos es un identificador válido? 2numero, numero-2, _numero2

_numero2 es válido. 2numero comienza con dígito (inválido). numero-2 contiene guion normal (inválido).

¿Cuántos bytes ocupa un long? ¿Y su rango?

Un long ocupa 8 bytes. Su rango es de -9,223,372,036,854,775,808 a +9,223,372,036,854,775,807.

¿Cuál es el resultado de 17 % 5? ¿Y de 15 / 3?

17 % 5 = 2 (el resto de la división). 15 / 3 = 5 (división exacta).

¿Qué ocurre al hacer double x = 3.7; int y = (int) x;?

y obtiene el valor 3. Se pierden los decimales (.7) porque int no puede representar decimales.

¿Puedo usar int como nombre de variable?

No. int es una palabra reservada de Java. Debes elegir otro nombre, como entero o numero.

¿Cuál es la diferencia entre ++x y x++?

++x (pre-incremento) incrementa primero y luego devuelve el valor. x++ (post-incremento) devuelve primero el valor antiguo, luego incrementa. En la mayoría de casos funcionan igual, pero en expresiones pueden diferir.

¿Cuál es el resultado de 2 + 3 * 4?

14. La multiplicación se ejecuta primero (precedencia), así que: 3 * 4 = 12, luego 2 + 12 = 14.

¿Qué significa final double PI = 3.14159;?

Define una constante llamada PI. Después de asignarle 3.14159, NO puedes cambiar su valor. Cualquier intento de asignación posterior da error.

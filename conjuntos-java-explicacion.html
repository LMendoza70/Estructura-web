Conjuntos: lo único que importa es quién pertenece

No hay posiciones, no hay orden garantizado, y jamás hay dos elementos iguales. Un conjunto solo responde una pregunta: ¿esto pertenece o no pertenece?

Conjunto A = {1, 2, 3, 4} · Conjunto B = {3, 4, 5, 6}

Intenta agregar un valor que ya existe en un conjunto: no se duplicará.

01 · Concepto de conjuntos

¿Qué es un conjunto?

Un conjunto (Set) es una colección de elementos donde ningún valor puede repetirse y, a diferencia de un arreglo o una lista, no existe un orden garantizado ni una posición numérica para acceder a sus elementos. Lo único relevante es si un elemento pertenece o no al conjunto.

Analogía: piensa en una bolsa de canicas de distintos colores. No importa en qué orden metiste las canicas a la bolsa, y si intentas meter una segunda canica exactamente del mismo color y tamaño que otra que ya está adentro, en realidad la bolsa "ya la tenía": no se duplica. Lo único que puedes preguntar con sentido es "¿hay una canica azul en la bolsa?", no "¿qué canica está en la posición 3?".
02 · Componentes

Las piezas de un conjunto

elemento

Cada valor individual que pertenece al conjunto.

unicidad

La regla central: si intentas agregar un elemento que ya existe, el conjunto simplemente lo ignora — no genera un duplicado ni un error.

pertenencia

La operación fundamental: preguntar si un valor específico está o no dentro del conjunto.

implementación interna

La implementación más común, HashSet, usa internamente la misma idea de función hash y cubetas que un diccionario — de hecho, un HashSet se construye por dentro sobre un HashMap.

03 · Función práctica

Dónde se usan los conjuntos para resolver problemas reales

Eliminar duplicados

Pasar una lista con repetidos por un conjunto es la forma más directa de quedarte solo con los valores únicos.

Verificar pertenencia rápidamente

Preguntar "¿este correo ya está registrado?" en O(1) promedio, sin recorrer toda la lista de usuarios.

Comparar dos colecciones

Encontrar qué tienen en común dos grupos (intersección), qué le falta a uno respecto al otro (diferencia), o combinarlos sin duplicar (unión).

Etiquetas o permisos únicos

Un conjunto de roles o etiquetas asignadas a un usuario, donde no tiene sentido que un mismo rol aparezca dos veces.

04 · Operaciones

Lo que se le puede hacer a un conjunto

add(valor)

Agrega un elemento. Si ya existía, no ocurre nada — el conjunto sigue teniendo un solo ejemplar.

remove(valor)

Elimina un elemento si está presente.

contains(valor)

Devuelve true o false según si el valor pertenece al conjunto.

size()

Devuelve cuántos elementos únicos tiene el conjunto.

import java.util.HashSet;
import java.util.Set;

Set<Integer> numeros = new HashSet<>();

numeros.add(3);
numeros.add(7);
numeros.add(3);   // se ignora: 3 ya estaba en el conjunto

System.out.println(numeros.size());        // 2, no 3
System.out.println(numeros.contains(7));  // true

numeros.remove(7);
System.out.println(numeros.contains(7));  // false

Operaciones de conjuntos matemáticos

Java permite realizar directamente las operaciones clásicas de la teoría de conjuntos usando los métodos de colecciones:

Set<Integer> a = new HashSet<>(List.of(1, 2, 3, 4));
Set<Integer> b = new HashSet<>(List.of(3, 4, 5, 6));

// Unión: todos los elementos de ambos, sin repetir
Set<Integer> union = new HashSet<>(a);
union.addAll(b);   // {1,2,3,4,5,6}

// Intersección: solo los que están en ambos
Set<Integer> interseccion = new HashSet<>(a);
interseccion.retainAll(b);   // {3,4}

// Diferencia: los que están en A pero no en B
Set<Integer> diferencia = new HashSet<>(a);
diferencia.removeAll(b);   // {1,2}
05 · Errores frecuentes

Lo que suele fallar

⚠
Intentar acceder por índice: un conjunto no tiene get(i) ni posiciones — si necesitas orden y acceso posicional, la estructura correcta es una lista, no un conjunto.
⚠
Esperar un orden de iteración predecible con HashSet: el orden no está garantizado. Si el orden de inserción importa, usa LinkedHashSet; si necesitas orden ascendente automático, usa TreeSet.
⚠
Confundir removeAll() con la intersección: removeAll(b) calcula la diferencia (A − B), quitando de A todo lo que está en B — no la intersección, que se logra con retainAll().
06 · Principio de Pareto

El 20% de reglas que explica el 80% de los conjuntos

  • Ningún elemento puede repetirse: agregar un duplicado no tiene efecto.
  • No hay índices ni orden garantizado (salvo que uses LinkedHashSet o TreeSet).
  • add(), remove() y contains() son, en promedio, tan rápidos como las operaciones de un diccionario — porque internamente usan el mismo mecanismo de hash.
  • Unión = addAll(); Intersección = retainAll(); Diferencia = removeAll().
  • Si el problema es "quiero saber si algo ya existe" o "quiero quitar duplicados", casi siempre la respuesta es un conjunto.
07 · Active recall

Ponte a prueba (haz clic en cada pregunta)

1. Si agregas el número 5 dos veces seguidas a un HashSet, ¿cuántas veces aparece dentro del conjunto?
Solo una vez. La regla de unicidad hace que el segundo add(5) no tenga ningún efecto.
2. ¿Qué método de Set calcula la intersección entre dos conjuntos?
retainAll(): conserva únicamente los elementos que también están presentes en el otro conjunto.
3. ¿Por qué no se puede escribir conjunto.get(0) como en un arreglo?
Porque un conjunto no tiene posiciones ni orden garantizado; su única operación de consulta relevante es preguntar si un valor pertenece (contains()), no recuperarlo por índice.
4. Tienes dos listas con posibles usuarios repetidos entre sí y quieres saber cuáles usuarios están en ambas listas a la vez. ¿Qué operación de conjuntos usarías?
La intersección (retainAll()): convertir cada lista en un conjunto y calcular los elementos que ambos conjuntos tienen en común.

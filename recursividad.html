Recursividad

Una función que se llama a sí misma para resolver un problema dividiéndolo en versiones más pequeñas del mismo problema — hasta llegar a un caso tan simple que ya no necesita dividirse más.

La clase: ¿qué es y cómo se sostiene?

La idea completa cabe en una frase; el resto es aprender a confiar en ella.

Piensa en dos espejos puestos uno frente al otro: cada reflejo contiene otro reflejo, cada vez más pequeño, hasta que ya no se distingue nada más. La recursividad funciona igual — cada llamada contiene una versión más pequeña del mismo problema, hasta llegar a una tan simple que se resuelve directamente, sin volver a llamarse.

Formalmente, la recursividad es una técnica de programación en la que una función se invoca a sí misma, de forma directa o indirecta, para resolver un problema descomponiéndolo en subproblemas del mismo tipo pero de menor tamaño. Toda función recursiva bien construida tiene exactamente dos partes:

Caso base

La condición que detiene la recursión. Se resuelve directamente, sin volver a llamar a la función. Sin caso base — o con uno mal definido — la función se llama infinitamente.

Caso recursivo

La función se llama a sí misma con una entrada más pequeña o más cercana al caso base. Cada llamada debe avanzar hacia esa condición de paro, nunca alejarse de ella.

pila

Cada vez que una función se llama a sí misma, Java apila (push) esa llamada en la pila de llamadas (call stack) y la deja en espera. Cuando por fin se alcanza el caso base, las llamadas empiezan a resolverse y a desapilarse (pop) en orden inverso — la última que entró es la primera que sale (LIFO). Si el caso base nunca llega, la pila crece sin control y Java lanza un StackOverflowError.

Tipos de recursividad

La misma idea, con cinco formas distintas de organizarse.

directa

Directa

La función se llama a sí misma dentro de su propio cuerpo. Es la forma más común: factorial(n) llamando a factorial(n-1).

indirecta

Indirecta

Una función A llama a una función B, y B vuelve a llamar a A, cerrando el ciclo entre dos o más funciones distintas.

de cola

De cola (tail)

La llamada recursiva es la última instrucción que se ejecuta, sin operaciones pendientes después. El resultado se acumula en un parámetro adicional.

no de cola

No de cola

Después de recibir el resultado de la llamada recursiva, la función todavía realiza una operación con él — como multiplicar en el factorial clásico.

múltiple

Múltiple o de árbol

La función se llama a sí misma más de una vez en el mismo cuerpo, generando un árbol de llamadas. Fibonacci y Torres de Hanoi son los ejemplos clásicos.

Ejemplos resueltos en Java

Cinco problemas, cada uno con un tipo de recursividad distinto.

Factorial

recursividad directa · no de cola

El ejemplo canónico. El caso base evita multiplicar por números negativos; cada llamada reduce n en 1, acercándose siempre al caso base.

public class Factorial {

    public static int factorial(int n) {
        // Caso base
        if (n == 0) {
            return 1;
        }
        // Caso recursivo: se acerca al caso base
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        System.out.println(factorial(5)); // 120
    }
}
Nota: es "no de cola" porque después de que factorial(n-1) retorna, todavía queda pendiente la multiplicación por n.

Fibonacci

recursividad múltiple / de árbol

Dos llamadas recursivas por invocación generan un árbol de llamadas que crece exponencialmente — útil para introducir el tema de complejidad algorítmica que se retoma en la Unidad II.

public class Fibonacci {

    public static int fib(int n) {
        // Caso base doble
        if (n == 0) return 0;
        if (n == 1) return 1;
        // Caso recursivo: dos llamadas
        return fib(n - 1) + fib(n - 2);
    }
}

Nota: observa que fib(2) y fib(1) se recalculan varias veces — el mismo subproblema se resuelve una y otra vez. Es el punto de partida perfecto para hablar de memoización más adelante.

Suma de un arreglo

recursividad directa · conecta con arreglos

El caso base es el arreglo vacío (índice fuera de rango); cada llamada avanza una posición.

public class SumaArreglo {

    public static int suma(int[] datos, int indice) {
        // Caso base: ya no quedan elementos
        if (indice == datos.length) {
            return 0;
        }
        // Caso recursivo
        return datos[indice] + suma(datos, indice + 1);
    }

    public static void main(String[] args) {
        int[] numeros = {4, 8, 15, 16, 23, 42};
        System.out.println(suma(numeros, 0)); // 108
    }
}

Búsqueda binaria

recursividad directa · preludio a la Unidad II

Cada llamada descarta la mitad del rango de búsqueda. El caso base es "ya no queda rango" o "el elemento del medio es el buscado".

public class BusquedaBinaria {

    public static int buscar(int[] arr, int objetivo, int izq, int der) {
        if (izq > der) {
            return -1; // Caso base: no encontrado
        }
        int medio = (izq + der) / 2;
        if (arr[medio] == objetivo) {
            return medio; // Caso base: encontrado
        } else if (arr[medio] < objetivo) {
            return buscar(arr, objetivo, medio + 1, der);
        } else {
            return buscar(arr, objetivo, izq, medio - 1);
        }
    }
}

Torres de Hanoi

recursividad múltiple / de árbol

Mover n discos requiere resolver dos subproblemas de n-1 discos, con un movimiento intermedio. El número mínimo de movimientos es 2n − 1.

public class TorresHanoi {

    public static void mover(int n, char origen, char destino, char auxiliar) {
        if (n == 0) {
            return; // Caso base: no hay disco que mover
        }
        mover(n - 1, origen, auxiliar, destino);
        System.out.println("Mover disco " + n + " de " + origen + " a " + destino);
        mover(n - 1, auxiliar, destino, origen);
    }

    public static void main(String[] args) {
        mover(3, 'A', 'C', 'B'); // 7 movimientos = 2^3 - 1
    }
}

Prácticas para los estudiantes

Cinco ejercicios progresivos, del nivel 1 al 5, siguiendo el mismo formato del banco de ejercicios del curso.

Nivel 1

Potencia de un número

Caso de uso: una calculadora necesita elevar un número base a un exponente entero sin usar operadores de potencia ni ciclos.

  • Implementar int potencia(int base, int exponente) de forma recursiva.
  • Definir con claridad el caso base (exponente 0).
  • No usar for, while ni Math.pow.
Nivel 2

Suma de dígitos

Caso de uso: un sistema de validación necesita sumar los dígitos de un número (por ejemplo, para calcular un dígito verificador).

  • Implementar int sumaDigitos(int n) que sume los dígitos de un entero positivo.
  • Usar el operador módulo y división entera para separar el último dígito en cada llamada.
  • Identificar el caso base cuando el número se reduce a un solo dígito.
Nivel 3

Invertir una cadena

Caso de uso: un módulo de validación de palíndromos necesita invertir una cadena de texto antes de compararla con la original.

  • Implementar String invertir(String texto) sin usar StringBuilder.reverse().
  • El caso base es la cadena vacía o de un solo carácter.
  • Extra: usar el resultado para determinar si una palabra es palíndromo.
Nivel 4

Máximo común divisor

Caso de uso: una aplicación de fracciones necesita simplificar resultados calculando el MCD de numerador y denominador.

  • Implementar int mcd(int a, int b) usando el algoritmo de Euclides: mcd(a, b) = mcd(b, a % b).
  • El caso base ocurre cuando b es 0.
  • Documentar si la implementación es de cola o no de cola, y justificar por qué.
Nivel 5

Torres de Hanoi con conteo

Caso de uso: se necesita no solo resolver el rompecabezas de Torres de Hanoi, sino reportar cuántos movimientos totales requirió, para comparar contra la fórmula teórica.

  • Extender el ejemplo de clase para que mover reciba un contador (por referencia, con un arreglo de tamaño 1, o retornándolo) y acumule el total de movimientos.
  • Comparar el resultado obtenido contra 2n − 1 para n = 3, 5 y 8 discos.
  • Incluir en el reporte técnico una breve reflexión sobre por qué este algoritmo crece tan rápido.

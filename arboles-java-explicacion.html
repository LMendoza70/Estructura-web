Árboles: cuando una estructura deja de ser una fila

Arreglos, listas, pilas y colas son lineales: cada elemento tiene un único "siguiente". Un árbol rompe esa regla — un nodo puede tener varios hijos, formando una jerarquía en vez de una fila.

Árbol binario de búsqueda: inserta un valor o prueba un recorrido.

Este es un Árbol Binario de Búsqueda (ABB): todo valor menor que un nodo va a su izquierda, todo mayor va a su derecha.

01 · Concepto de árboles

¿Qué es un árbol?

Un árbol es una estructura de datos jerárquica y no lineal: un conjunto de nodos conectados de tal forma que existe un único nodo inicial (la raíz) y cada nodo puede tener cero o más nodos "hijos", sin que existan ciclos — nunca se puede volver a un nodo ya visitado siguiendo las conexiones hacia abajo.

Analogía: piensa en el árbol genealógico de una familia o en el organigrama de una empresa. Hay una persona en la cima (el fundador, la raíz), esa persona tiene subordinados directos (hijos), y esos subordinados pueden tener los suyos propios. Nadie es su propio jefe ni el jefe de alguien que ya está por encima de él — no hay ciclos.
02 · Componentes

El vocabulario de un árbol

Raíz

El único nodo sin padre; el punto de entrada a todo el árbol.

Padre / hijo

Un nodo conectado directamente hacia abajo con otro es su padre; el de abajo es su hijo.

Hoja

Un nodo sin hijos: el final de una rama.

Subárbol

Cualquier nodo, junto con todos sus descendientes, forma un árbol más pequeño dentro del árbol completo.

Altura

La distancia (en número de conexiones) desde la raíz hasta la hoja más lejana.

Nivel / profundidad

La distancia desde la raíz hasta un nodo específico; la raíz está en el nivel 0.

En un árbol binario, cada nodo tiene como máximo dos hijos, distinguidos como "izquierdo" y "derecho". Cuando además se cumple que todo valor a la izquierda es menor y todo valor a la derecha es mayor que el nodo, se llama Árbol Binario de Búsqueda (ABB) — el tipo que estás viendo en el visualizador de arriba.

03 · Función práctica

Dónde aparecen los árboles en la práctica

Sistemas de archivos

Carpetas que contienen carpetas y archivos: una jerarquía clásica de árbol.

El DOM de una página web

Cada etiqueta HTML es un nodo con posibles hijos (otras etiquetas anidadas).

Árboles de decisión

Cada nodo representa una pregunta o condición; cada rama, una posible respuesta.

Búsqueda eficiente (ABB)

Un Árbol Binario de Búsqueda permite buscar, insertar y eliminar en O(log n) en promedio, mucho más rápido que recorrer una lista completa.

04 · Operaciones

Insertar y buscar en un Árbol Binario de Búsqueda

public class NodoArbol<T extends Comparable<T>> {
    T dato;
    NodoArbol<T> izquierdo;
    NodoArbol<T> derecho;

    NodoArbol(T dato) { this.dato = dato; }
}

public class ArbolBinarioBusqueda<T extends Comparable<T>> {
    private NodoArbol<T> raiz;

    public void insertar(T valor) {
        raiz = insertar(raiz, valor);
    }

    private NodoArbol<T> insertar(NodoArbol<T> nodo, T valor) {
        if (nodo == null) {
            return new NodoArbol<>(valor);   // aquí va el nuevo nodo
        }
        if (valor.compareTo(nodo.dato) < 0) {
            nodo.izquierdo = insertar(nodo.izquierdo, valor);
        } else if (valor.compareTo(nodo.dato) > 0) {
            nodo.derecho = insertar(nodo.derecho, valor);
        }
        return nodo;
    }

    public boolean buscar(T valor) {
        return buscar(raiz, valor);
    }

    private boolean buscar(NodoArbol<T> nodo, T valor) {
        if (nodo == null) return false;   // caso base: no encontrado
        if (valor.compareTo(nodo.dato) == 0) return true;
        return valor.compareTo(nodo.dato) < 0
            ? buscar(nodo.izquierdo, valor)
            : buscar(nodo.derecho, valor);
    }
}

Eliminar un nodo es la operación más delicada: si el nodo tiene dos hijos, hay que reemplazarlo por su sucesor (el menor valor de su subárbol derecho) para no romper la propiedad de orden del ABB — un detalle que suele dejarse para un tema aparte por su complejidad.

05 · Algoritmos de recorrido en árboles

Cuatro formas distintas de visitar los mismos nodos

Preorden (raíz → izquierda → derecha)

Visita el nodo actual antes que sus hijos. Útil para copiar o serializar la estructura del árbol.

private void preorden(NodoArbol<T> nodo) {
    if (nodo == null) return;
    System.out.println(nodo.dato);
    preorden(nodo.izquierdo);
    preorden(nodo.derecho);
}

Inorden (izquierda → raíz → derecha)

En un ABB, este recorrido visita los valores en orden ascendente — la forma más directa de obtener los datos ya ordenados.

private void inorden(NodoArbol<T> nodo) {
    if (nodo == null) return;
    inorden(nodo.izquierdo);
    System.out.println(nodo.dato);
    inorden(nodo.derecho);
}

Postorden (izquierda → derecha → raíz)

Visita los hijos antes que el nodo actual. Útil cuando hay que procesar dependencias antes que el elemento que depende de ellas, como al eliminar un árbol completo de memoria.

private void postorden(NodoArbol<T> nodo) {
    if (nodo == null) return;
    postorden(nodo.izquierdo);
    postorden(nodo.derecho);
    System.out.println(nodo.dato);
}

Por niveles (BFS)

Visita nodo por nodo, nivel por nivel, de arriba hacia abajo. A diferencia de los tres anteriores (que son recursivos y usan la pila de llamadas), este recorrido usa explícitamente una cola.

private void porNiveles(NodoArbol<T> raiz) {
    if (raiz == null) return;
    Queue<NodoArbol<T>> cola = new LinkedList<>();
    cola.add(raiz);
    while (!cola.isEmpty()) {
        NodoArbol<T> actual = cola.poll();
        System.out.println(actual.dato);
        if (actual.izquierdo != null) cola.add(actual.izquierdo);
        if (actual.derecho != null) cola.add(actual.derecho);
    }
}

06 · Errores frecuentes

Lo que suele fallar

⚠
Olvidar el caso base en la recursión: todo recorrido recursivo necesita if (nodo == null) return; al inicio, igual que cualquier función recursiva — sin él, se produce un NullPointerException.
⚠
Confundir árbol binario con ABB: todo Árbol Binario de Búsqueda es un árbol binario, pero no todo árbol binario cumple la propiedad de orden (izquierda menor, derecha mayor) que hace eficiente la búsqueda.
⚠
Esperar O(log n) sin garantías: si los valores se insertan en un ABB ya ordenados (por ejemplo 1, 2, 3, 4...), el árbol degenera en una lista enlazada y las operaciones caen a O(n).
07 · Principio de Pareto

El 20% de reglas que explica el 80% de los árboles

  • Un árbol es jerárquico: un nodo puede tener varios hijos, y no hay ciclos.
  • En un ABB: menor a la izquierda, mayor a la derecha — esa regla es lo que hace posible buscar en O(log n).
  • Preorden, inorden y postorden solo cambian cuándo se visita la raíz respecto a sus hijos.
  • Inorden en un ABB siempre entrega los valores ordenados de menor a mayor.
  • Si necesitas el nodo más cercano a la raíz primero, usa recorrido por niveles (BFS con cola); si necesitas explorar a fondo antes de retroceder, usa preorden/inorden/postorden (DFS con pila o recursión).
08 · Active recall

Ponte a prueba (haz clic en cada pregunta)

1. ¿Qué diferencia estructural fundamental separa a un árbol de una lista enlazada?
En una lista, cada nodo tiene como máximo un "siguiente" (estructura lineal). En un árbol, un nodo puede tener varios hijos, formando una jerarquía en vez de una secuencia.
2. En un Árbol Binario de Búsqueda, ¿qué recorrido entrega los valores ya ordenados de menor a mayor?
El recorrido inorden (izquierda, raíz, derecha).
3. ¿Qué estructura de apoyo usa el recorrido por niveles, y en qué se diferencia de los otros tres recorridos?
Usa una cola (FIFO) de forma explícita, mientras que preorden, inorden y postorden son recursivos y se apoyan implícitamente en la pila de llamadas.
4. ¿Por qué insertar valores ya ordenados (1, 2, 3, 4...) en un ABB es un mal escenario?
Porque cada nuevo valor siempre es mayor que el anterior, así que el árbol crece en una sola dirección y termina pareciéndose a una lista enlazada, perdiendo la ventaja de O(log n) y cayendo a O(n).

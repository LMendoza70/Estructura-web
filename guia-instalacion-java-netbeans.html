Guía de instalación: entorno de desarrollo Java + NetBeans

Preparación del equipo para trabajar los objetos de aprendizaje, las prácticas y el caso de estudio del curso, desde cero hasta el primer programa ejecutado.

0 / 7 pasos completados
Antes de empezar

Requisitos del equipo

  • Windows 10/11, macOS 12 o superior, o una distribución Linux reciente (Ubuntu 22.04+).
  • Al menos 4 GB de RAM libres (8 GB recomendado) y 3 GB de espacio en disco.
  • Conexión a internet solo para la descarga inicial; una vez instalado, NetBeans funciona sin conexión.
  • Permisos de administrador en el equipo, necesarios para ambas instalaciones.
✓Todo el material del curso usa Java estándar (sin frameworks externos), así que no necesitas nada más que el JDK y el IDE para trabajar cualquiera de las 11 guías interactivas o el banco de ejercicios.
Paso 1

Descargar e instalar el JDK

El JDK (Java Development Kit) incluye el compilador (javac) y el entorno de ejecución (java) — es lo que realmente convierte y corre tu código, con o sin un IDE.

Distribución recomendada: Eclipse Temurin (antes AdoptOpenJDK), la misma build de OpenJDK usada por la mayoría de las universidades y empresas — es gratuita, de código abierto y sin restricciones de licencia para uso educativo, a diferencia del JDK de Oracle. Se descarga en adoptium.net.

Versión recomendada: JDK 21 (LTS). Es la versión con soporte a largo plazo más estable y ampliamente compatible con NetBeans; ninguna guía del curso requiere características exclusivas de versiones más nuevas (como JDK 25 LTS, la más reciente al momento de esta guía).

  1. Entra a adoptium.net → pestaña "Latest release" → selecciona JDK 21 (LTS), sistema Windows, arquitectura x64, paquete .msi.
  2. Ejecuta el instalador descargado. Acepta todas las opciones por defecto.
  3. En el paso "Custom Setup", asegúrate de que esté marcada la opción "Set JAVA_HOME variable" — esto te ahorra el paso 3 manual.
  4. Finaliza la instalación y reinicia cualquier ventana de terminal que tuvieras abierta.
  1. Entra a adoptium.net → selecciona JDK 21 (LTS), sistema macOS, arquitectura según tu Mac (x64 para Intel, aarch64 para Apple Silicon), paquete .pkg.
  2. Abre el instalador .pkg descargado y sigue el asistente.
  3. Si macOS bloquea la app por venir de un "desarrollador no identificado": ve a Ajustes del Sistema → Privacidad y Seguridad y pulsa "Abrir de todas formas".

Para Ubuntu/Debian, la forma más simple es por línea de comandos (repositorio oficial de Temurin):

sudo apt update
sudo apt install -y wget apt-transport-https gpg
wget -qO- https://packages.adoptium.net/artifactory/api/gpg/key/public | sudo gpg --dearmor -o /usr/share/keyrings/adoptium.gpg
echo "deb [signed-by=/usr/share/keyrings/adoptium.gpg] https://packages.adoptium.net/artifactory/deb $(awk -F= '/VERSION_CODENAME/{print$2}' /etc/os-release) main" | sudo tee /etc/apt/sources.list.d/adoptium.list
sudo apt update
sudo apt install -y temurin-21-jdk
Paso 2

Verificar la instalación en terminal

Abre una terminal (cmd o PowerShell en Windows, Terminal en macOS/Linux) y ejecuta:

java -version
javac -version

Debes ver algo similar a openjdk version "21.0.x" en ambos comandos. Si el sistema responde "java" no se reconoce como un comando (Windows) o command not found (macOS/Linux), continúa con el Paso 3.

Paso 3

Configurar la variable de entorno JAVA_HOME

Esta variable indica a otras herramientas dónde está instalado el JDK. Si marcaste la opción del instalador en Windows en el Paso 1, puedes omitir este paso.

  1. Busca "Variables de entorno" en el menú de inicio y abre "Editar las variables de entorno del sistema".
  2. Pulsa el botón "Variables de entorno...".
  3. En "Variables del sistema", pulsa "Nueva..." → nombre JAVA_HOME, valor la ruta de instalación (por ejemplo C:\Program Files\Eclipse Adoptium\jdk-21.0.x-hotspot).
  4. Edita la variable Path y agrega %JAVA_HOME%\bin.
  5. Cierra y vuelve a abrir la terminal para que tome efecto.

El instalador de Temurin ya configura esto automáticamente. Para verificarlo o forzarlo manualmente, agrega esto a tu ~/.zshrc (o ~/.bash_profile):

export JAVA_HOME=$(/usr/libexec/java_home -v 21)
export PATH=$JAVA_HOME/bin:$PATH

Luego ejecuta source ~/.zshrc o abre una terminal nueva.

Agrega estas líneas al final de tu ~/.bashrc (o ~/.zshrc):

export JAVA_HOME=/usr/lib/jvm/temurin-21-jdk-amd64
export PATH=$JAVA_HOME/bin:$PATH

Ajusta la ruta según lo que muestre update-alternatives --list java. Después ejecuta source ~/.bashrc.

⚠Un error común es apuntar JAVA_HOME a la carpeta bin en lugar de la carpeta raíz del JDK. La ruta correcta termina en algo como jdk-21.0.x-hotspot, no en ...\bin.
Paso 4

Descargar e instalar NetBeans IDE

Descarga la versión estable más reciente desde netbeans.apache.org/download — la página siempre ofrece la última disponible, así que no te guíes por un número de versión fijo. Elige el paquete "Java SE" o el bundle completo (incluye soporte web, que no necesitas pero no estorba).

  1. Descarga el instalador .exe para Windows.
  2. Ejecútalo y sigue el asistente; si pregunta por el JDK a usar, selecciona la carpeta donde instalaste Temurin 21.
  3. Acepta la ubicación de instalación por defecto.
  1. Descarga el archivo .dmg para macOS.
  2. Ábrelo y arrastra NetBeans a la carpeta Aplicaciones.
  3. Si macOS bloquea la apertura, repite el paso de "Abrir de todas formas" del Paso 1.

Opción recomendada: instalar como paquete Snap (mantiene actualizaciones automáticas):

sudo snap install netbeans --classic

Alternativa: descarga el .zip desde netbeans.apache.org/download, descomprime y ejecuta bin/netbeans.

Paso 5

Verificar que NetBeans detecta el JDK

  1. Abre NetBeans.
  2. Ve al menú Tools → Java Platforms (o Herramientas → Plataformas Java si está en español).
  3. Debe aparecer JDK 21 en la lista, marcado como plataforma por defecto. Si no aparece, pulsa "Add Platform..." y navega manualmente hasta la carpeta de instalación del JDK.
Paso 6

Crear el proyecto base del curso

  1. File → New Project...
  2. Categoría Java with Ant (o Java with Maven → Java Application si prefieres Maven) → Java Application.
  3. Nombre del proyecto: estructura-de-datos-practicas.
  4. Desmarca "Create Main Class" si prefieres organizar por paquetes primero (recomendado).

Para que coincida con la organización usada en las guías y en el repositorio del curso, crea un paquete por tema dentro de com.uthh.edd, agrupados por unidad (clic derecho sobre Source Packages → New → Java Package):

com.uthh.edd ├── unidad1 │ ├── tda │ ├── recursion │ ├── arreglos │ └── genericos ├── unidad2 │ ├── listas │ ├── pilas │ ├── colas │ └── ordenamiento └── unidad3 ├── arboles ├── diccionarios └── conjuntos
✓Esta estructura es la misma que usa el repositorio src-java/ del curso, así que el código que escribas en NetBeans se puede copiar directamente a los paquetes correspondientes cuando subas tus prácticas a GitHub.
Paso 6.1 (recomendado)

Configurar el proyecto: codificación UTF-8

Como el material y los comentarios del código usan acentos y "ñ", configura el proyecto para evitar caracteres corruptos al compartir archivos entre Windows, macOS y Linux:

  1. Clic derecho sobre el proyecto → Properties.
  2. Categoría Sources → campo Encoding → selecciona UTF-8.
Paso 7

Ejecutar el primer programa

Dentro del paquete com.uthh.edd.unidad1.tda, crea una clase nueva (clic derecho → New → Java Class) llamada PruebaEntorno:

package com.uthh.edd.unidad1.tda;

public class PruebaEntorno {
    public static void main(String[] args) {
        System.out.println("Entorno configurado correctamente.");
    }
}

Ejecuta con clic derecho sobre el archivo → Run File (o Shift+F6). Si ves el mensaje en la consola inferior de NetBeans, el entorno está listo para las 11 guías del curso y el banco de ejercicios.

Listas ligadas en Java: del proyecto a la consola

En esta práctica construirás una lista ligada simple desde cero. Crearás el proyecto en Apache NetBeans, programarás las clases, probarás el programa con un menú interactivo y finalmente lo ejecutarás desde la consola (terminal de Windows, macOS o Linux), como lo haría un programa real.

⏱ Duración estimada: 2 h 👥 Individual o en pareja 🧰 JDK 17+ · NetBeans · Consola

1 Verificar el JDK y NetBeans

Objetivo: confirmar que tu equipo puede compilar y ejecutar programas Java.

NetBeans necesita un JDK (Java Development Kit) instalado. Si ya seguiste la guía de instalación de Java y NetBeans, solo verifica que todo esté listo.

1.1 Verifica el JDK desde la consola

Abre la terminal de tu sistema y escribe:

terminal
java -version
javac -version

Ambos comandos deben mostrar una versión (17 o superior). Si aparece un error del tipo "no se reconoce como un comando", revisa la sección de problemas al final de la práctica.

1.2 Abre NetBeans

Inicia Apache NetBeans. Si es la primera vez, confirma que en Tools → Java Platforms aparezca tu JDK como plataforma predeterminada.

💡 Consejo: Crea una carpeta exclusiva para tus prácticas, por ejemplo EDD/Practicas. Así todos tus proyectos quedan ordenados y fáciles de entregar.

2 Crear el proyecto en NetBeans

Objetivo: generar la estructura base de un proyecto Java de consola.

2.1 Nuevo proyecto

  1. Ve al menú File → New Project… (o presiona Ctrl+Shift+N / Cmd+Shift+N).
  2. En la categoría Java with Ant, selecciona Java Application. Pulsa Next.
  3. Escribe el nombre del proyecto: PracticaListasLigadas.
  4. Elige la carpeta de ubicación (la carpeta EDD/Practicas que creaste).
  5. Deja marcada la opción Create Main Class y escribe el nombre Main junto con el paquete.
  6. En Package name escribe com.uthh.edd.unidad2.listas (formato del curso: com.uthh.edd.unidadN.tema).
  7. Pulsa Finish.

2.2 Entiende la estructura creada

En la ventana Projects verás una carpeta con esta organización:

Projects

Presiona F11 (Build Project). Si la ventana Output muestra BUILD SUCCESSFUL, la base del proyecto está lista.

3 Crear la clase Nodo

Objetivo: programar la pieza básica de la lista: un nodo con un dato y una referencia al siguiente.

Imagina una búsqueda del tesoro: cada pista te dice dónde está la siguiente pista. Un nodo funciona igual: guarda un dato y la "dirección" del siguiente nodo.

3.1 Crea el archivo

Clic derecho sobre el paquete com.uthh.edd.unidad2.listas → New → Java Class… → nombre: Nodo.

3.2 Escribe el código

Nodo.java
package com.uthh.edd.unidad2.listas;

/**
 * Nodo de una lista ligada simple.
 * Guarda un dato entero y una referencia al siguiente nodo.
 */
public class Nodo {

    int dato;          // valor almacenado en el nodo
    Nodo siguiente;     // referencia al siguiente nodo (null si es el último)

    public Nodo(int dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}
💡 Lee esto en voz alta: "Un Nodo tiene un dato y tiene un siguiente". La palabra this significa "este objeto": this.dato es el dato de este nodo.

4 Crear la clase ListaEnlazada

Objetivo: implementar las operaciones básicas: insertar, buscar, eliminar, mostrar y medir el tamaño.

4.1 Crea el archivo

Clic derecho sobre el paquete → New → Java Class… → nombre: ListaEnlazada.

4.2 Escribe el código

ListaEnlazada.java
package com.uthh.edd.unidad2.listas;

public class ListaEnlazada {

    private Nodo cabeza;   // primer nodo de la lista
    private int tamanio;   // cantidad de nodos almacenados

    public ListaEnlazada() {
        this.cabeza = null;
        this.tamanio = 0;
    }

    public boolean estaVacia() {
        return cabeza == null;
    }

    public int getTamanio() {
        return tamanio;
    }

    // Inserta al inicio. Costo: O(1)
    public void insertarInicio(int valor) {
        Nodo nuevo = new Nodo(valor);
        nuevo.siguiente = cabeza;   // el nuevo apunta al antiguo primero
        cabeza = nuevo;             // el nuevo pasa a ser la cabeza
        tamanio++;
    }

    // Inserta al final. Costo: O(n)
    public void insertarFinal(int valor) {
        Nodo nuevo = new Nodo(valor);
        if (estaVacia()) {
            cabeza = nuevo;
        } else {
            Nodo actual = cabeza;
            while (actual.siguiente != null) {
                actual = actual.siguiente;   // avanzar hasta el último nodo
            }
            actual.siguiente = nuevo;
        }
        tamanio++;
    }

    public boolean buscar(int valor) {
        Nodo actual = cabeza;
        while (actual != null) {
            if (actual.dato == valor) {
                return true;
            }
            actual = actual.siguiente;
        }
        return false;
    }

    // Elimina la primera aparición del valor. Devuelve true si lo eliminó.
    public boolean eliminar(int valor) {
        if (estaVacia()) {
            return false;
        }
        if (cabeza.dato == valor) {       // caso 1: está en la cabeza
            cabeza = cabeza.siguiente;
            tamanio--;
            return true;
        }
        Nodo anterior = cabeza;               // caso 2: está en medio o al final
        Nodo actual = cabeza.siguiente;
        while (actual != null) {
            if (actual.dato == valor) {
                anterior.siguiente = actual.siguiente;  // "saltar" el nodo
                tamanio--;
                return true;
            }
            anterior = actual;
            actual = actual.siguiente;
        }
        return false;
    }

    public void mostrar() {
        if (estaVacia()) {
            System.out.println("(lista vacía)");
            return;
        }
        Nodo actual = cabeza;
        while (actual != null) {
            System.out.print(actual.dato);
            if (actual.siguiente != null) {
                System.out.print(" -> ");
            }
            actual = actual.siguiente;
        }
        System.out.println();
    }
}
Error frecuente: en eliminar, si olvidas el caso 1 (eliminar la cabeza), la lista se rompe. Además, no uses == para comparar textos: aquí comparamos int, por eso sí funciona.

4.3 Dibuja lo que pasa en memoria

5 Crear el menú principal (Main)

Objetivo: crear un programa de consola interactivo que use la lista.

NetBeans ya creó Main.java. Ábrelo (doble clic) y reemplaza todo su contenido con el siguiente código:

Main.java
package com.uthh.edd.unidad2.listas;

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        ListaEnlazada lista = new ListaEnlazada();
        int opcion;

        do {
            System.out.println("\n===== MENÚ LISTA LIGADA =====");
            System.out.println("1. Insertar al inicio");
            System.out.println("2. Insertar al final");
            System.out.println("3. Buscar un valor");
            System.out.println("4. Eliminar un valor");
            System.out.println("5. Mostrar la lista");
            System.out.println("6. Ver tamaño");
            System.out.println("0. Salir");
            System.out.print("Opción: ");
            opcion = teclado.nextInt();

            switch (opcion) {
                case 1:
                    System.out.print("Valor: ");
                    lista.insertarInicio(teclado.nextInt());
                    break;
                case 2:
                    System.out.print("Valor: ");
                    lista.insertarFinal(teclado.nextInt());
                    break;
                case 3:
                    System.out.print("Valor a buscar: ");
                    int buscado = teclado.nextInt();
                    System.out.println(lista.buscar(buscado)
                            ? "Sí está en la lista"
                            : "No está en la lista");
                    break;
                case 4:
                    System.out.print("Valor a eliminar: ");
                    int eliminado = teclado.nextInt();
                    System.out.println(lista.eliminar(eliminado)
                            ? "Eliminado"
                            : "No encontrado");
                    break;
                case 5:
                    lista.mostrar();
                    break;
                case 6:
                    System.out.println("Tamaño: " + lista.getTamanio());
                    break;
                case 0:
                    System.out.println("Hasta luego");
                    break;
                default:
                    System.out.println("Opción inválida");
            }
        } while (opcion != 0);

        teclado.close();
    }
}
💡 ¿Por qué do … while? El menú debe mostrarse al menos una vez y repetirse hasta que el usuario elija 0. Es el patrón típico de un menú de consola.

7 Ejecutar desde la consola

Objetivo: ejecutar el programa fuera de NetBeans, usando solo la terminal. Así es como se ejecutan los programas en servidores y sistemas reales.

7.1 Genera el archivo ejecutable (.jar)

En NetBeans presiona F11 (Build Project). NetBeans crea automáticamente el archivo:

Ruta generada
PracticaListasLigadas/dist/PracticaListasLigadas.jar

7.2 Ejecuta desde la terminal de tu sistema

Elige la pestaña de tu sistema operativo:

Abre Símbolo del sistema (cmd) o PowerShell. Luego escribe (ajusta la ruta a tu carpeta):

cd C:\EDD\Practicas\PracticaListasLigadas\dist
java -jar PracticaListasLigadas.jar

Abre la app Terminal. Luego escribe (ajusta la ruta a tu carpeta):

cd ~/EDD/Practicas/PracticaListasLigadas/dist
java -jar PracticaListasLigadas.jar

Abre tu terminal favorita. Luego escribe (ajusta la ruta a tu carpeta):

cd ~/EDD/Practicas/PracticaListasLigadas/dist
java -jar PracticaListasLigadas.jar
🔑 Qué significa cada parte: java arranca la máquina virtual de Java · -jar indica que vas a ejecutar un paquete JAR · PracticaListasLigadas.jar es tu programa. El jar ya sabe cuál es la clase Main gracias al manifiesto que NetBeans genera.

7.3 Alternativa manual (sin NetBeans)

Para entender qué hace realmente el compilador, también puedes compilar a mano. Desde la carpeta raíz del proyecto (PracticaListasLigadas):

# 1. Compilar todos los .java y guardar las .class en la carpeta "bin"
javac -d bin src/com/uthh/edd/unidad2/listas/*.java

# 2. Ejecutar la clase principal (nota: se usa el nombre del paquete completo)
java -cp bin com.uthh.edd.unidad2.listas.Main
💡 Observa la diferencia: javac compila (crea archivos .class), y java ejecuta. En el comando java escribes el nombre completo de la clase, con puntos en lugar de carpetas. Así se llama nombre cualificado.

★ Lo esencial (Principio de Pareto)

Si recuerdas solo estas cinco ideas, dominarás el 80% de la práctica:

  1. Un nodo = dato + referencia al siguiente. Toda la lista se construye así.
  2. La cabeza es la puerta de entrada. Si la pierdes, pierdes la lista.
  3. Para insertar o eliminar en medio, necesitas al anterior. Por eso usamos la variable anterior.
  4. Siempre actualiza tamanio. Es fácil olvidarlo y dar un dato incorrecto.
  5. Compila en NetBeans, ejecuta en consola. El .jar de dist/ es tu programa final.

? Active recall: pon a prueba tu comprensión

Intenta responder antes de abrir cada pregunta.

¿Por qué insertarInicio es O(1) y insertarFinal es O(n)?
En insertarInicio solo cambiamos dos referencias, sin importar cuántos nodos haya. En insertarFinal debemos recorrer toda la lista hasta el último nodo, así que el tiempo crece con n.
¿Qué pasaría si en eliminar no existiera el caso de la cabeza?
Si el valor estuviera en la cabeza, el ciclo empezaría con actual = cabeza.siguiente y nunca lo encontraría, por lo que no se eliminaría. Además, la variable anterior no tendría nodo previo que modificar.
¿Qué significa la palabra this en el constructor de Nodo?
Significa "este objeto". this.dato = dato asigna el parámetro recibido al atributo del nodo que se está creando, distinguiendo ambos nombres.
¿Cuál es la diferencia entre ejecutar desde NetBeans y desde java -jar?
NetBeans compila y ejecuta dentro de su entorno (botón F6). java -jar ejecuta el archivo ya empaquetado en dist/ directamente en la terminal, sin necesidad del IDE. Es como funcionan los programas reales.

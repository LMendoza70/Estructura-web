Arreglos: una fila de casilleros numerados

Un arreglo es una colección de casillas del mismo tipo, de tamaño fijo, numeradas desde 0, donde llegar a cualquier casilla toma el mismo tiempo sin importar cuál elijas.

int[] numeros = {12, 45, 7, 88, 3, 60};

Cada casilla tiene un índice fijo. Acceder a numeros[3] es directo: no hace falta recorrer las anteriores.

01 · Concepto (técnica Feynman)

¿Qué es un arreglo?

Un arreglo (array) es una estructura que guarda varios valores del mismo tipo en un bloque de memoria contiguo, accesibles mediante un índice numérico que comienza en 0.

Analogía: imagina un casillero de gimnasio con 6 compartimentos numerados del 0 al 5. Todos los compartimentos son del mismo tamaño (mismo tipo de dato), la cantidad de compartimentos no cambia una vez instalado el mueble (tamaño fijo), y para abrir el compartimento número 3 no necesitas abrir antes el 0, 1 y 2: vas directo a él.
02 · Características

Lo que define a un arreglo en Java

Tamaño fijo

Una vez creado, no puede crecer ni encogerse. Si necesitas una colección que cambie de tamaño, se usa ArrayList en su lugar.

Homogéneo

Todos los elementos son del mismo tipo declarado: todos int, todos String, todos de una misma clase, etc.

Indexado desde 0

El primer elemento está en la posición 0 y el último en longitud - 1.

Acceso directo

Ir a arreglo[i] toma el mismo tiempo sin importar qué tan grande sea el arreglo ni qué índice se pida.

03 · Declaración, creación y manipulación

Los tres elementos que necesitas dominar

01

Declaración

Se indica el tipo de dato y el nombre de la variable, seguido de [].

02

Creación

Se reserva la memoria con new indicando el tamaño, o se inicializa directamente con valores.

03

Manipulación

Se lee o escribe un valor por índice, se consulta .length, o se recorre completo.

// 1. Declaración: solo se indica el tipo y el nombre
int[] numeros;

// 2. Creación: reservar memoria para 6 posiciones (todas en 0 por defecto)
numeros = new int[6];

// Declaración + creación en un solo paso, con valores iniciales
int[] numeros2 = {12, 45, 7, 88, 3, 60};

// 3. Manipulación
numeros[0] = 100;              // asignar un valor en el índice 0
int primero = numeros[0];   // leer el valor del índice 0
int tamano = numeros.length;   // consultar cuántos elementos tiene

// Recorrido con for clásico (usa el índice)
for (int i = 0; i < numeros.length; i++) {
    System.out.println("posición " + i + ": " + numeros[i]);
}

// Recorrido con for-each (no necesita el índice)
for (int valor : numeros) {
    System.out.println(valor);
}
04 · Arreglos de objetos y multidimensionales

Más allá de los tipos primitivos

Un arreglo también puede guardar objetos (por ejemplo, String[] o un arreglo de una clase propia) y puede tener más de una dimensión, útil para representar tablas o matrices.

String[] nombres = {"Ana", "Luis", "Marco"};

// Matriz 3x3 (arreglo de arreglos)
int[][] tablero = new int[3][3];
tablero[1][2] = 7;  // fila 1, columna 2
05 · Errores frecuentes

Lo que suele fallar

⚠
ArrayIndexOutOfBoundsException: ocurre al usar un índice menor a 0 o mayor o igual a length. Si el arreglo tiene 6 elementos, los índices válidos van de 0 a 5, nunca hasta 6.
⚠
Confundir .length con .length(): los arreglos usan la propiedad numeros.length (sin paréntesis); los String usan el método texto.length() (con paréntesis).
⚠
Esperar que el arreglo cambie de tamaño: new int[6] siempre tendrá 6 posiciones. Para agregar o quitar elementos dinámicamente se necesita otra estructura, como ArrayList.
06 · Principio de Pareto

El 20% de reglas que explica el 80% de los arreglos

  • Declarar (tipo[] nombre;) y crear (new tipo[tamaño]) son pasos distintos, aunque suelen escribirse juntos.
  • El primer índice siempre es 0; el último siempre es length - 1.
  • El tamaño se fija al crear el arreglo y no cambia después.
  • Todo elemento del arreglo debe ser del mismo tipo declarado.
  • Usa for clásico cuando necesitas el índice; usa for-each cuando solo necesitas los valores.
07 · Active recall

Ponte a prueba (haz clic en cada pregunta)

1. Si declaras int[] datos = new int[8];, ¿cuáles son los índices válidos?
Del 0 al 7. El índice 8 ya está fuera de rango y provocaría un ArrayIndexOutOfBoundsException.
2. ¿Cuál es la diferencia entre declarar y crear un arreglo?
Declarar solo indica el tipo y el nombre de la variable (int[] datos;); crear reserva efectivamente la memoria con new indicando el tamaño (datos = new int[8];). Pueden escribirse en la misma línea, pero son dos acciones distintas.
3. ¿Por qué el acceso a arreglo[i] es igual de rápido para cualquier índice?
Porque los elementos están en memoria contigua y de tamaño uniforme: Java calcula directamente la dirección de memoria de la posición i, sin tener que recorrer los elementos anteriores.
4. ¿Qué pasa si necesitas agregar un elemento más a un arreglo ya lleno?
Un arreglo no puede crecer: hay que crear uno nuevo, más grande, y copiar los elementos existentes (como hace internamente ArrayList), o usar directamente una estructura de tamaño dinámico.

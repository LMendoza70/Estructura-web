TDA Fracción

Caso de uso

Una calculadora escolar necesita representar fracciones (numerador/denominador) y sumarlas entre sí, garantizando que el denominador nunca pueda quedar en cero.

Requisitos
  • Atributos numerador y denominador privados.
  • Constructor que rechace denominador 0.
  • Método sumar(Fraccion otra) que devuelva una nueva fracción.
Ver solución (Java) 
class Fraccion {
    private int numerador;
    private int denominador;

    public Fraccion(int numerador, int denominador) {
        if (denominador == 0) {
            throw new IllegalArgumentException("El denominador no puede ser 0");
        }
        this.numerador = numerador;
        this.denominador = denominador;
    }

    public Fraccion sumar(Fraccion otra) {
        int n = this.numerador * otra.denominador + otra.numerador * this.denominador;
        int d = this.denominador * otra.denominador;
        return new Fraccion(n, d);
    }
}

Agenda de citas de un consultorio

Caso de uso

Un consultorio dental necesita agendar citas por hora, evitando que se registren dos citas que se traslapen en el mismo horario.

Requisitos
  • Método agendar(horaInicio, horaFin) que valide traslape contra citas ya guardadas.
  • Método cancelar(horaInicio).
  • Estado interno de citas no accesible directamente desde fuera de la clase.
Ver solución (Java) 
import java.util.List;
import java.util.ArrayList;

class Agenda {
    private List<int[]> citas = new ArrayList<>();

    public boolean agendar(int inicio, int fin) {
        for (int[] c : citas) {
            if (inicio < c[1] && fin > c[0]) {
                return false; // traslape con una cita existente
            }
        }
        citas.add(new int[]{inicio, fin});
        return true;
    }

    public boolean cancelar(int inicio) {
        return citas.removeIf(c -> c[0] == inicio);
    }
}

Inventario de un producto

Caso de uso

Una tienda necesita controlar el stock de un producto: debe poder surtir y vender unidades, pero nunca debe permitirse que el stock quede en negativo, y debe poder consultarse si el stock está por debajo de un umbral de reorden.

Requisitos
  • Métodos surtir(cantidad) y vender(cantidad) con validación.
  • Método necesitaReabastecimiento() según un umbral configurable.
  • Excepción propia si se intenta vender más de lo disponible.
Ver solución (Java) 
class Inventario {
    private int stock;
    private final int umbral;

    public Inventario(int umbral) {
        this.umbral = umbral;
    }

    public void surtir(int cantidad) {
        stock += cantidad;
    }

    public void vender(int cantidad) {
        if (cantidad > stock) {
            throw new IllegalStateException("Stock insuficiente para vender " + cantidad);
        }
        stock -= cantidad;
    }

    public boolean necesitaReabastecimiento() {
        return stock < umbral;
    }
}

Cuenta bancaria con historial de movimientos

Caso de uso

Extiende la CuentaBancaria vista en clase para que registre internamente cada depósito y retiro con fecha, y permita consultar el historial completo sin que quien lo consulta pueda alterarlo.

Requisitos
  • Lista interna privada de movimientos.
  • obtenerHistorial() debe devolver una copia, nunca la referencia interna.
  • Cada movimiento registra tipo, monto y saldo resultante.
Ver solución (Java) 
import java.util.List;
import java.util.ArrayList;

class CuentaBancaria {
    private double saldo;
    private List<String> historial = new ArrayList<>();

    public void depositar(double monto) {
        saldo += monto;
        historial.add("Depósito $" + monto + " - saldo $" + saldo);
    }

    public void retirar(double monto) throws IllegalStateException {
        if (monto > saldo) {
            throw new IllegalStateException("Fondos insuficientes");

        saldo -= monto;
        historial.add("Retiro $" + monto + " - saldo $" + saldo);
    }

        return new ArrayList<>(historial); // copia: la interna nunca se expone

Recursividad

5 ejercicios

Identificar el caso base y el caso recursivo, y trazar la pila de llamadas resultante.

Nivel 1

Potencia de un número

Caso de uso

Una calculadora científica necesita calcular base^exponente usando únicamente multiplicaciones sucesivas, sin usar bucles.

Requisitos
  • Método potencia(base, exponente).
  • Caso base: exponente 0 devuelve 1.
  • Caso recursivo: base * potencia(base, exponente-1).
Ver solución (Java) 
public static long potencia(int base, int exponente) {
    if (exponente == 0) {
        return 1;                                   // caso base
    }
    return base * potencia(base, exponente - 1);    // caso recursivo
}

Nivel 3

Verificar si una palabra es palíndromo

Caso de uso

Un juego de palabras necesita detectar automáticamente si una palabra ingresada por el usuario se lee igual al derecho y al revés.

Requisitos
  • Método esPalindromo(String texto).
  • Compara primer y último carácter, y recursa sobre el resto.
  • Caso base: cadena de longitud 0 o 1.
Ver solución (Java) 
public static boolean esPalindromo(String texto) {
    if (texto.length() <= 1) {         // caso base
        return true;
    }
    char primero = texto.charAt(0);
    char ultimo = texto.charAt(texto.length() - 1);
    if (primero != ultimo) {
        return false;
    }
    return esPalindromo(texto.substring(1, texto.length() - 1));
}
Nivel 4

Invertir una lista enlazada

Caso de uso

Un reproductor de música quiere ofrecer la opción "reproducir en orden inverso" sobre su lista de canciones enlazada, sin crear una lista nueva desde cero.

Requisitos
  • Método recursivo que reciba la cabeza de la lista y devuelva la nueva cabeza invertida.
  • Reutiliza los mismos nodos, solo reconecta referencias.
  • Caso base: nodo actual es null o es el último.
Ver solución (Java) 
class Nodo {
    Object valor;
    Nodo siguiente;
    Nodo(Object v) { this.valor = v; }
}

public static Nodo invertir(Nodo nodo) {
    if (nodo == null || nodo.siguiente == null) {
        return nodo;                       // caso base
    }
    Nodo nuevaCabeza = invertir(nodo.siguiente);
    nodo.siguiente.siguiente = nodo;       // reconecta las referencias
    nodo.siguiente = null;
    return nuevaCabeza;
}

Torres de Hanói

Caso de uso

Un juego educativo de lógica pide mover una torre de discos de un poste a otro, respetando que nunca un disco más grande quede sobre uno más pequeño, usando un poste auxiliar.

Requisitos
  • Método hanoi(n, origen, destino, auxiliar).
  • Imprime cada movimiento individual de disco.
  • Caso base: un solo disco (n == 1).
Ver solución (Java) 
public static void hanoi(int n, char origen, char destino, char auxiliar) {
    if (n == 1) {
        System.out.println("Mueve disco 1 de " + origen + " a " + destino);
        return;
    }
    hanoi(n - 1, origen, auxiliar, destino);
    System.out.println("Mueve disco " + n + " de " + origen + " a " + destino);
    hanoi(n - 1, auxiliar, destino, origen);
}

Nivel 1

Máximo y mínimo en calificaciones

Caso de uso

Un profesor capturó las calificaciones de un grupo en un arreglo y necesita saber cuál fue la calificación más alta y la más baja del examen.

Requisitos
  • Recorrer el arreglo una sola vez.
  • Devolver ambos valores (por ejemplo, en un arreglo de tamaño 2).
Ver solución (Java) 
public static int[] maximoYMinimo(int[] calif) {
    int max = calif[0];
    int min = calif[0];
    for (int c : calif) {
        if (c > max) max = c;
        if (c < min) min = c;
    }
    return new int[]{max, min};
}

Invertir el orden de turnos sin arreglo auxiliar

Caso de uso

Una clínica quiere invertir el orden de atención de su lista de turnos del día (el último paciente pasa primero), modificando el mismo arreglo en memoria, sin crear uno nuevo.

Requisitos
  • Intercambiar elementos de los extremos hacia el centro (dos punteros).
  • No usar un segundo arreglo del mismo tamaño.
Ver solución (Java) 
public static void invertir(int[] turnos) {
    int i = 0, j = turnos.length - 1;
    while (i < j) {
        int aux = turnos[i];
        turnos[i] = turnos[j];
        turnos[j] = aux;
        i++;
        j--;
    }
}

Matriz de asistencia semanal

Caso de uso

Un maestro quiere llevar el control de asistencia de sus alumnos durante la semana (5 días) usando una matriz, y al final calcular cuántos días asistió cada alumno y cuántos alumnos asistieron cada día.

Requisitos
  • Arreglo bidimensional boolean[][] asistencia (alumnos x días).
  • Totales por fila (por alumno) y por columna (por día).
Ver solución (Java) 
public static void reporte(boolean[][] asistencia) {
    int alumnos = asistencia.length;
    int dias = asistencia[0].length;

    for (int a = 0; a < alumnos; a++) {
        int total = 0;
        for (int d = 0; d < dias; d++) {
            if (asistencia[a][d]) total++;
        }
        System.out.println("Alumno " + a + ": " + total + " días");
    }

    for (int d = 0; d < dias; d++) {
        int total = 0;
        for (int a = 0; a < alumnos; a++) {
            if (asistencia[a][d]) total++;
        }
        System.out.println("Día " + d + ": " + total + " alumnos");
    }
}

Elemento más repetido de un arreglo genérico

import java.util.HashMap;
import java.util.Map;

public static <T> T masRepetido(T[] datos) {
    Map<T, Integer> cont = new HashMap<>();
    for (T d : datos) {
        cont.put(d, cont.getOrDefault(d, 0) + 1);
    }
    T mejor = datos[0];
    int max = 0;
    for (Map.Entry<T, Integer> e : cont.entrySet()) {
        if (e.getValue() > max) {
            max = e.getValue();
            mejor = e.getKey();
        }
    }
    return mejor;
}

Caché con capacidad máxima

Caso de uso

Una aplicación necesita una caché reutilizable (para distintos tipos de clave y valor) que guarde un número limitado de resultados, descartando el más antiguo cuando se llena.

Requisitos
  • Clase Cache<K, V> con capacidad fija en el constructor.
  • Método put(K,V) que descarte la entrada más antigua si ya está llena.
Ver solución (Java) 
import java.util.LinkedHashMap;
import java.util.Map;

public class Cache<K, V> extends LinkedHashMap<K, V> {
    private final int capacidad;

    public Cache(int capacidad) {
        super(capacidad, 0.75f, true); // access-order: "más antiguo" = menos usado
        this.capacidad = capacidad;
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        return size() > capacidad; // descarta el más antiguo al exceder
    }

    @Override
    public V put(K clave, V valor) {
        return super.put(clave, valor);
    }
}

Nivel 1

Lista de tareas pendientes

Caso de uso

Una aplicación de productividad necesita agregar tareas al final de una lista y mostrarlas todas en el orden en que se capturaron.

Requisitos
  • Lista simple con insertarFinal(tarea).
  • Método mostrarTodas().
Ver solución (Java) 
class ListaTareas {
    private Nodo cabeza;

    private static class Nodo {
        String tarea;
        Nodo siguiente;
        Nodo(String t) { this.tarea = t; }
    }

    public void insertarFinal(String tarea) {
        Nodo nuevo = new Nodo(tarea);
        if (cabeza == null) { cabeza = nuevo; return; }
        Nodo aux = cabeza;
        while (aux.siguiente != null) aux = aux.siguiente;
        aux.siguiente = nuevo;
    }

    public void mostrarTodas() {
        for (Nodo aux = cabeza; aux != null; aux = aux.siguiente) {
            System.out.println(aux.tarea);
        }
    }
}
Nivel 2

Eliminar una tarea específica

Caso de uso

Sobre la misma lista de tareas, el usuario marca una tarea como completada y esta debe eliminarse de la lista, sin importar en qué posición se encuentre.

Requisitos
  • Método eliminar(valor) que reconecte los nodos vecinos.
  • Manejar el caso de eliminar la cabeza.
Ver solución (Java) 
public void eliminar(String tarea) {
    if (cabeza == null) return;

    // caso límite: eliminar la cabeza
    if (cabeza.tarea.equals(tarea)) {
        cabeza = cabeza.siguiente;
        return;
    }

    Nodo previo = cabeza;
    while (previo.siguiente != null && !previo.siguiente.tarea.equals(tarea)) {
        previo = previo.siguiente;
    }
    if (previo.siguiente != null) {
        previo.siguiente = previo.siguiente.siguiente; // reconecta vecinos
    }
}

Turnos rotativos de un juego de mesa

Caso de uso

Un juego de mesa para 5 jugadores necesita repartir el turno en orden y, al llegar al último jugador, volver automáticamente al primero, indefinidamente.

Requisitos
  • Lista circular simple con 5 nodos.
  • Método siguienteTurno() que avance y regrese al inicio tras el último.

class Turnos {
    private Nodo actual;

    private static class Nodo {
        String jugador;
        Nodo siguiente;
        Nodo(String j) { jugador = j; }
    }

    public Turnos(String[] jugadores) {
        Nodo ultimo = null;
        for (String j : jugadores) {
            Nodo nuevo = new Nodo(j);
            if (actual == null) { actual = nuevo; ultimo = nuevo; }

        return actual.jugador;
    }
}
Nivel 5

Fusionar dos listas ordenadas

Caso de uso

Dos sucursales de una tienda enviaron cada una su lista de productos más vendidos, ya ordenada por código de producto, y se necesita combinarlas en una sola lista ordenada para el reporte general.

Requisitos
  • Método fusionar(lista1, lista2) que devuelva una sola lista simple ordenada.
  • No debe volver a ordenar todo desde cero: aprovechar que ambas ya vienen ordenadas.
Ver solución (Java) 
static class Nodo {
    int valor;
    Nodo siguiente;
    Nodo(int v) { valor = v; }
}

public static Nodo fusionar(Nodo l1, Nodo l2) {
    Nodo centinela = new Nodo(0); // nodo temporal
    Nodo fin = centinela;

    while (l1 != null && l2 != null) {
        if (l1.valor <= l2.valor) { fin.siguiente = l1; l1 = l1.siguiente; }
        else                       { fin.siguiente = l2; l2 = l2.siguiente; }
        fin = fin.siguiente;
    }
    fin.siguiente = (l1 != null) ? l1 : l2; // resto de la lista que quede
    return centinela.siguiente;
}

Pilas

5 ejercicios

Reconocer problemas que requieren procesar "lo último agregado, primero".

Nivel 1

Paréntesis balanceados

Caso de uso

Un editor de código necesita marcar en rojo una línea si los paréntesis, corchetes o llaves que contiene no están correctamente balanceados.

Requisitos
  • Apilar cada símbolo de apertura.
  • Al encontrar un cierre, hacer pop() y comparar.
Ver solución (Java) 
import java.util.*;

public static boolean estaBalanceado(String exp) {
    Stack<Character> pila = new Stack<>();
    Map<Character, Character> cierres = Map.of(')', '(', ']', '[', '}', '{');
    for (char c : exp.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') {
            pila.push(c);
        } else if (cierres.containsKey(c)) {
            if (pila.isEmpty() || pila.pop() != cierres.get(c)) {
                return false;
            }
        }
    }
    return pila.isEmpty();
}
Nivel 2

Evaluar una expresión postfija

Caso de uso

Una calculadora científica interna representa las operaciones en notación postfija (por ejemplo, 3 4 +) y necesita evaluarlas correctamente.

Requisitos
  • Apilar operandos; al leer un operador, desapilar dos y apilar el resultado.
  • El resultado final queda como único elemento de la pila.
Ver solución (Java) 
import java.util.*;

public static int evaluarPostfija(String[] tokens) {
    Stack<Integer> pila = new Stack<>();
    for (String t : tokens) {
        if (Character.isDigit(t.charAt(0))) {
            pila.push(Integer.parseInt(t));
        } else {
            int b = pila.pop();
            int a = pila.pop();
            switch (t) {
                case "+": pila.push(a + b); break;
                case "-": pila.push(a - b); break;
                case "*": pila.push(a * b); break;
                case "/": pila.push(a / b); break;
            }
        }
    }
    return pila.pop(); // el único elemento que queda
}

Convertir una expresión infija a postfija

Caso de uso

Antes de poder evaluar expresiones matemáticas escritas de forma normal (infija), el sistema necesita convertirlas primero a notación postfija respetando la precedencia de operadores.

Requisitos
  • Pila auxiliar de operadores.
  • Reglas de precedencia entre + - * /.
Ver solución (Java) 
import java.util.*;

public static List<String> infijaAPostfija(String[] tokens) {
    Stack<String> ops = new Stack<>();
    List<String> salida = new ArrayList<>();
    Map<String, Integer> precedencia = Map.of("+", 1, "-", 1, "*", 2, "/", 2);

    for (String t : tokens) {
        if (!precedencia.containsKey(t)) {
            salida.add(t);              // operando: va directo a la salida
        } else {
            // saca operadores de igual o mayor precedencia
            while (!ops.isEmpty() && precedencia.get(ops.peek()) >= precedencia.get(t)) {
                salida.add(ops.pop());
            }
            ops.push(t);
        }
    }
    while (!ops.isEmpty()) salida.add(ops.pop());
    return salida;
}

public static void burbuja(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int aux = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = aux;
            }
        }
    }
}

        for (int j = 0; j < n - 1 - i; j++) {
            cont++;

    int cont = 0;
    for (int i = 1; i < arr.length; i++) {
        int key = arr[i], j = i - 1;
        while (j >= 0 && arr[j] > key) {
            cont++;
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
    return cont;
}

BFS y DFS en un mapa de rutas de transporte

Caso de uso

Un sistema de transporte público quiere saber si existe una ruta entre dos estaciones, explorando primero por cercanía (BFS con cola) y comparándolo contra una exploración a profundidad (DFS con pila).

Requisitos
  • Representar el mapa como una estructura de conexiones entre estaciones.
  • Implementar ambos recorridos y comparar el orden en que visitan las estaciones.
Ver solución (Java) 
import java.util.*;

// BFS: explora por cercanía con una cola
public static List<String> bfs(Map<String, List<String>> rutas, String inicio) {
    List<String> orden = new ArrayList<>();
    Set<String> visitados = new HashSet<>();
    Queue<String> cola = new LinkedList<>();
    cola.add(inicio); visitados.add(inicio);
    while (!cola.isEmpty()) {
        String actual = cola.poll();
        orden.add(actual);
        for (String v : rutas.getOrDefault(actual, List.of()))
            if (!visitados.contains(v)) { visitados.add(v); cola.add(v); }
    }
    return orden;
}

// DFS: explora a profundidad con una pila
public static List<String> dfs(Map<String, List<String>> rutas, String inicio) {
    List<String> orden = new ArrayList<>();
    Set<String> visitados = new HashSet<>();
    Stack<String> pila = new Stack<>();
    pila.push(inicio);
    while (!pila.isEmpty()) {
        String actual = pila.pop();
        if (!visitados.contains(actual)) {
            visitados.add(actual);
            orden.add(actual);
            for (String v : rutas.getOrDefault(actual, List.of()))
                if (!visitados.contains(v)) pila.push(v);
        }
    }
    return orden;
}

        if (usernames.contains(username)) {
            return false; // ya está en uso: rechaza
        }
        usernames.add(username);
        return true;
    }
}

Asistentes en común a dos eventos

Caso de uso

Los organizadores de una conferencia quieren saber qué personas asistieron tanto al evento de la mañana como al de la tarde, a partir de dos listas de asistencia independientes.

Requisitos
  • Convertir ambas listas en conjuntos.
  • Calcular la intersección con retainAll().
Ver solución (Java) 
import java.util.*;

public static Set<String> asistentesEnComun(List<String> manana, List<String> tarde) {
    Set<String> comun = new HashSet<>(manana);
    comun.retainAll(new HashSet<>(tarde)); // intersección: los de ambos
    return comun;
}

Productos exclusivos frente a la competencia

Caso de uso

El área comercial de una tienda quiere saber qué productos de su catálogo no ofrece la competencia, comparando dos listas de productos.

Requisitos
  • Calcular la diferencia (catálogo propio − catálogo de competencia) con removeAll().
  • Mostrar el resultado ordenado alfabéticamente.
Ver solución (Java) 
import java.util.*;

public static Set<String> productosExclusivos(Set<String> propio, Set<String> competencia) {
    TreeSet<String> resultado = new TreeSet<>(propio); // TreeSet ordena
    resultado.removeAll(competencia); // diferencia: quedan los exclusivos
    return resultado;                  // y ya van ordenados alfabéticamente
}

Unión de etiquetas entre artículos relacionados

Caso de uso

Un blog quiere fusionar las etiquetas de dos artículos relacionados en un solo conjunto de etiquetas combinadas, sin que ninguna etiqueta quede duplicada, para mostrarlas juntas en una sección de "temas relacionados".

Requisitos
  • Calcular la unión con addAll() sobre una copia de uno de los conjuntos.
  • Mantener el conjunto original de cada artículo sin modificar.
Ver solución (Java) 
import java.util.*;

public static Set<String> unirEtiquetas(Set<String> articulo1, Set<String> articulo2) {
    Set<String> combinadas = new HashSet<>(articulo1); // copia: no altera el original
    combinadas.addAll(articulo2);                       // unión sin duplicados
    return combinadas;
}
